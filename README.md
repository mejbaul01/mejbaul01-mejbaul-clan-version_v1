# Mejba Clan · Rest of Clans (Fantasy Match-3 Jewel Quest)

**Mejba Clan: Rest of Clans** is a modern, responsive, mobile-first match-3 fantasy jewel puzzle game built with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## 💻 লোকাল ডেভেলপমেন্ট ও বিল্ড:

```bash
# ডিপেন্ডেন্সি ইনস্টল
npm install

# লোকাল ডেভেলপমেন্ট সার্ভার চালু (Port 3000)
npm run dev

# টাইপচেক ও লিন্ট
npm run lint

# প্রোডাকশন বিল্ড
npm run build
```
